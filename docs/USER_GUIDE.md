# 用户使用指南

欢迎使用 Adaptive LP Vault！这是一个自动化的流动性管理金库，你存入 WETH + USDC 后，系统会自动把资金分配到 Uniswap V2 和 V3 的流动性池里，帮你赚取做市手续费。

这份指南会带你一步步完成：连接钱包 → 存款 → 查看持仓 → 赎回 → 触发再平衡赚奖励 → 参与治理。

---

## 1. 开始之前

在使用之前，你需要准备好以下几样东西：

| 需要什么 | 说明 |
|---------|------|
| MetaMask 钱包 | 浏览器插件，如果你还没有，去 [metamask.io](https://metamask.io) 下载安装 |
| Sepolia 测试网 ETH | 用来付 gas（交易手续费），可以去 [Sepolia Faucet](https://sepolia-faucet.pk910.de/) 领 |
| WETH 和 USDC | 你要存入金库的两种币，测试网环境下可以在交易所或水龙头获取 |
| 前端页面 | 部署好的前端地址（见项目 README 中的部署信息） |

> 💡 这是测试网项目，所有代币都是测试币，没有真实价值，放心操作。

### 切换到 Sepolia 网络

1. 点击 MetaMask 图标
2. 点击顶部的网络切换按钮（默认显示"Ethereum Mainnet"）
3. 选择 "Sepolia"
   - 如果列表里没有，点击 "Add Network" 添加
   -  RPC URL: `https://sepolia.infura.io/v3/YOUR_INFURA_KEY`
   -  Chain ID: `11155111`

---

## 2. 连接钱包

1. 打开前端页面
2. 点击右上角的 **「连接钱包」** 按钮
3. MetaMask 弹出确认窗口，点击 **「连接」**
4. 连接成功后，右上角会显示你的钱包地址（ shortened 格式，如 `0x1234...abcd`）和网络徽章

> ⚠️ 如果显示"未连接"或网络不对，检查 MetaMask 是否切到了 Sepolia 网络。

---

## 3. 存入资金

这一步把你的 WETH 和 USDC 存进金库，获得 ALP 份额。

### 操作步骤

1. 点击顶部的 **「💰 存取款」** tab（默认就在这里）
2. 在「存入流动性」区域：
   - **WETH 数量**：输入你要存多少 WETH
   - **USDC 数量**：输入你要存多少 USDC
3. 输入后下方会实时显示：
   - 当前 TWAP 价格
   - 预计获得多少 ALP 份额
   - 你的资金占金库的比例
4. 点击 **「存入流动性」** 按钮
5. MetaMask 会弹出交易确认：
   - **第一次存款**：需要先分别授权 WETH 和 USDC（前端会自动提示，授权后再点存款）
   - 确认交易，等待链上确认

### ⚠️ 重要提醒

- **必须同时存入 WETH 和 USDC 两种币**！只存一种会导致资金只能进单边仓位，无常损失大
- 首次存款需要两次授权交易（WETH 一次、USDC 一次），之后就不用再授权了
- 授权是无限授权（Max Approval），如果你想撤销，可以去 Etherscan 操作

## 4. 查看你的持仓

### 顶部概览

连接钱包后，顶部卡片会显示：

| 数据 | 含义 |
|------|------|
| WETH 余额 | 你钱包里的 WETH |
| USDC 余额 | 你钱包里的 USDC |
| 金库份额 (ALP) | 你在金库里的份额数量 |
| 持仓价值 (USDC) | 你的份额当前价值（美元计价） |

### 数据看板

点击 **「📈 数据看板」** tab，可以看到：

| 数据 | 含义 |
|------|------|
| TVL (USDC) | 整个金库的总锁仓价值 |
| TWAP 价格 | 当前 Uniswap 池子的时间加权平均价格 |
| 再平衡次数 | 金库历史上做过多少次再平衡 |
| 累计手续费 | 金库总共赚了多少做市手续费 |
| 资金分布图 | 资金分布在：闲置 / Uniswap V2 / V3 0.05% / V3 0.30% |
| 策略参数 | 当前金库的各项策略参数（阈值、滑点、TWAP 窗口等） |

## 5. 赎回资金

如果你想把资金从金库里取出来：

### 操作步骤

1. 在 **「💰 存取款」** tab，往下滚动到「赎回流动性」区域
2. **赎回份额 (ALP)**：输入你想赎回多少 ALP 份额
   - 点击旁边的 `max` 可以全部赎回
3. 输入后会实时显示：
   - 预计收到多少 WETH
   - 预计收到多少 USDC
   - 你要赎回的比例
4. 点击 **「赎回流动性」** 按钮
5. MetaMask 确认交易，等待链上确认

> ⚠️ 赎回会触发金库从所有做市头寸中撤出流动性，所以需要一点时间处理。

## 6. 触发再平衡（赚奖励）

再平衡是金库根据市场行情自动调整资金分布的过程。**任何人都可以触发再平衡**，而且如果这次再平衡赚了钱，触发者可以获得 **5% 的 USDC 奖励**！

### 什么时候触发？

看「🔄 再平衡」tab 里的两个指标：

| 指标 | 什么时候值得触发 |
|------|----------------|
| **冷却状态** | 必须是"冷却已结束"才能触发（正常 10 分钟，高波动时 30 分钟） |
| **价格偏离度** | 偏离 ≥ 5% 时（显示绿色"建议触发"），说明市场价格偏离了 TWAP 参考价，再平衡有机会赚手续费 |

### 操作步骤

1. 点击 **「🔄 再平衡」** tab
2. 查看：
   - 冷却状态（是否已结束）
   - 当前价格偏离度（百分比）
   - 累计手续费
   - 待领取奖励
3. 如果冷却结束且偏离度合适，点击 **「🔄 触发再平衡」** 按钮
4. MetaMask 确认交易
5. 再平衡成功后：
   - 如果这次操作产生了正收益，你的"待领取奖励"会增加
   - 奖励是 USDC，存在激励合约里

> 💡 小技巧：如果冷却还在进行中（显示"冷却中 XX 秒"），等倒计时结束再点。

## 7. 参与治理

金库的策略参数（比如 TWAP 窗口、再平衡阈值、滑点保护等）可以通过链上治理投票修改。

### 前置条件

你需要持有 **ALP-GOV 治理代币**。如果你没有，可以通过项目方分发获得。

### 操作步骤

1. 点击 **「🗳️ 治理」** tab
2. 顶部显示你的 ALP-GOV 余额
3. **委托投票权**（第一次需要做）：
   - 点击"委托"按钮
   - 输入你想委托给自己还是别人
   - 确认交易
4. **创建提案**：
   - 选择要修改的参数类型（比如"调整 TWAP 窗口"）
   - 输入新值
   - 写一句提案说明
   - 提交提案
5. **投票**：
   - 在提案列表里找到你要投的提案
   - 选择"赞成"或"反对"
   - 确认投票交易

> ⚠️ 治理流程有时间锁：提案通过后不会立即生效，需要等待时间锁期。

## 8. 常见问题

### Q: 为什么必须同时存 WETH 和 USDC？

A: 金库是做双边流动性的（V2 和 V3 都需要两种币配对）。只存一种币的话，资金只能进单边仓位，无常损失会大很多。前端只提供双币存款入口，就是为了避免你误操作。

### Q: 什么是滑点？为什么会有滑点保护？

A: 滑点是指交易时实际成交价格跟预期价格的偏差。金库设了滑点保护（默认 1%），如果成交偏离超过 1%，交易会自动失败，防止你在剧烈波动时被"三明治攻击"或吃大亏。

### Q: 再平衡冷却期是多久？为什么有时候要等？

A: 正常情况下是 10 分钟，市场波动很大（>50%）时会自动延长到 30 分钟。冷却期是为了防止有人频繁触发再平衡刷奖励。

### Q: 再平衡的奖励从哪来？

A: 奖励来自激励合约里的 USDC 资金池。每次再平衡产生正收益时，触发者可以获得收益的 5% 作为奖励。奖励池需要项目方手动充值，用完了就暂时没有奖励了。

### Q: 为什么我的资金显示在"闲置"？

A: 刚存进去的资金会先停在"闲置"区域，等下一次再平衡时，系统会自动把它分配到 V2 和 V3 的流动性池里。

### Q: 交易失败了怎么办？

A: 常见原因：
- gas 不够 → 去领更多 Sepolia ETH
- 滑点超限 → 等一等再试，或者市场波动太大
- 冷却还没结束 → 看再平衡 tab 的倒计时
- 网络不对 → 检查 MetaMask 是否在 Sepolia
